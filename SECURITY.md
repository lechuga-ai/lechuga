# Security

If you find a way to read someone else's chats, spend someone else's credits, get past the invite gate or into `/admin`, or anything else that shouldn't be possible, please tell us privately before telling anyone else: **hello@lechuga.ai**.

Say what you did and what happened. We'll reply within a few days, fix it, and credit you in the What's new page if you'd like. Please don't test against other people's accounts or run anything that floods the service; an account of your own on lechuga.ai, or a local copy, is enough to show almost any problem.

There is no bug bounty. Lechuga is a side project run by two people.
